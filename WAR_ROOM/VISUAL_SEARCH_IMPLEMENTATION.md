# Visual Search Implementation

## 1. Procedural Semantic Image Pipeline
To dominate Google Lens and Image Packs, the actual file stored on the CDN must possess semantic value. UUIDs (`c9f0b8a2.webp`) provide zero context.

### Edge Worker Pipeline (`src/app/api/generate/route.ts`)
```typescript
function getProceduralFilename(entityData: any, uniqueId: string) {
  // Pulls context from the active entity graph
  const intent = entityData.useCaseSlug || 'professional';
  const aesthetic = entityData.styleSlug || 'aesthetic';
  const action = 'ai-portrait';
  
  // Output: picfomo-cinematic-actor-ai-portrait-9xj4.jpg
  return `picfomo-${aesthetic}-${intent}-${action}-${uniqueId}.jpg`;
}
```

## 3. Dynamic OpenGraph Generation (`src/app/api/og/route.tsx`)
We deploy a Vercel `ImageResponse` endpoint to dynamically generate social preview cards that trigger high CTRs on LinkedIn/X.

* **URL Structure:** `/api/og?post_id=123&style=Corporate`
* **Rendering Layout:**
  * Background: The actual generated `post.image_url` blurred (50px).
  * Foreground: The generated image prominently displayed.
  * Overlay Text: "1 Selfie. 20 Seconds. Identity-Lock™ Active."
* **Psychology:** When shared, the card promises an instant, high-quality transformation, driving massive social referral traffic.

## 4. Image Sitemap Indexing
Standard sitemaps are ignored for deep image indexing.
* We must deploy `src/app/image-sitemap-[chunk].xml/route.ts`.
* Every `<url>` must contain `<image:image>` with the `<image:title>`, `<image:caption>`, and critically, `<image:license>`. 
* The license declaration forces the "Licensable" badge in Google Images, establishing enterprise-grade authority over the asset.
