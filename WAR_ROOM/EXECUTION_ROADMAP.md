# Execution Roadmap: Programmatic Scale

## 1. Phase 1: 30-Day Plan (Infrastructure & Transactional Nodes)
**Goal: Capture bottom-of-funnel traffic and finalize the programmatic engine.**

* **Week 1: The Competitor Hijack.**
  * Launch the `/compare/[slug]` architecture.
  * Build 20 competitor comparison pages (Aragon, HeadshotPro, BetterPic, Canva).
  * Inject the empirical LLM markdown tables and FAQ schemas.
* **Week 2: The Core Entity Hubs.**
  * Launch the `/platforms` and `/identities` root hub pages.
  * Migrate `src/data/*.ts` into the Cloudflare D1 relational mapping structure (`taxonomy_nodes`, `taxonomy_edges`).
* **Week 3: The 100x Taxonomy Seeding.**
  * Seed the database with 100 Professions, 50 Aesthetics, and 20 Platforms.
  * Set up the dynamic route catch-alls (`app/identity/[slug]/page.tsx`).
* **Week 4: The Visual Search Engine.**
  * Deploy the procedural EXIF injection and semantic renaming pipeline in `/api/generate`.
  * Launch the `/api/og` dynamic OpenGraph image generator.

## 2. Phase 2: 90-Day Plan (Scale & Interlinking)
**Goal: Flood the index with 1,000+ high-quality programmatic nodes.**

* **Month 2: The Content Injection.**
  * Ensure the `<CommunityGrid>` is successfully pulling live 24-hour fresh database posts into every programmatic node.
  * Launch the `sitemap-usecases-[chunk].xml` index to handle the URL explosion securely.
* **Month 3: The SmartLinker Web.**
  * Deploy the D1-powered `<SmartLinker />` across all 1,000 nodes, ensuring Sibling and Upward linking to trap PageRank within the commercial silos.
  * Build the "Pillar Pages" (e.g., The Ultimate Guide to Professional Digital Identity) and begin acquiring external backlinks to flow authority downward.

## 3. Phase 3: 6-Month Plan (Semantic Moat & Agentic Web)
**Goal: Build an impenetrable GEO moat and transition to the API economy.**

* **Month 4: Reddit & Sentiment Consolidation.**
  * Launch the `/authenticity` and `/reddit-reviews` hubs. Use these to intercept all "looks fake" queries and establish the "Anti-Yassification" narrative.
* **Month 5: The Data Studies Hub.**
  * Publish 5 massive empirical data studies on AI facial accuracy to serve as primary citation bait for LLM RAG pipelines.
* **Month 6: MCP & Agent Integration.**
  * Expose the PicFOMO Identity-Lock generation pipeline via Model Context Protocol (MCP).
  * As users transition from typing in Google to commanding Apple Intelligence or ChatGPT ("Update my LinkedIn photo"), PicFOMO will be the native, integrated execution engine.

## 4. ROI Prioritization Mandate
Always build the Transactional (`/compare`) and High-Urgency (`/platform/linkedin`) nodes first. Do not build the "Astronaut AI Headshots" node until the core commercial silos are fully generating revenue. Speed and LLM optimization are our ultimate competitive weapons.
