# Entity Generation Engine (Operational Automation)

## 1. System Architecture
To scale to 100,000+ nodes, manual database entry is impossible. We implement a **Cloudflare Scheduled Worker** (Cron Trigger) that acts as an autonomous SEO entity generator, querying trending APIs and LLMs to seed `p_entities`.

### Pipeline Execution Flow (`src/workers/entity-generator.ts`)
1. **Trend Ingestion:** Worker hits TikTok/Pinterest/Google Trends APIs for surging aesthetic or career keywords.
2. **LLM Semantic Structuring:** Passes raw keywords to Groq/Llama-3.
   - *Prompt:* "Generate a PicFOMO programmatic entity for [Keyword]. Output JSON: { slug, canonical_name, h1_formula, emotional_hook, faqs }."
3. **Deduplication Check:** Runs a Levenshtein distance & Vector Similarity check against existing slugs in D1 to prevent cannibalization (e.g., rejecting `software-engineers` if `software-engineer` exists).
4. **D1 Ingestion:** Inserts the validated entity into `p_entities` with `is_active = 0` (Pending Quality Review).

## 2. Deduplication & Semantic Merging Logic
Using Cloudflare Vectorize (or D1 full-text search) to enforce uniqueness.

```typescript
// Executable D1 Deduplication Check
async function isEntityUnique(db: D1Database, proposedSlug: string, parentType: string) {
  const normalizedSlug = proposedSlug.toLowerCase().replace(/[^a-z0-9]+/g, '-');
  
  // 1. Exact Match Check
  const exact = await db.prepare("SELECT id FROM p_entities WHERE slug = ?").bind(normalizedSlug).first();
  if (exact) return { unique: false, reason: "exact_match" };

  // 2. Levenshtein / LIKE Check for Plurals & Variants
  // Example: Prevent "tech-founders" if "tech-founder" exists
  const baseStem = normalizedSlug.replace(/s$/, ''); // Basic stemming
  const { results } = await db.prepare(`
    SELECT slug FROM p_entities 
    WHERE type = ? AND slug LIKE ?
  `).bind(parentType, `%${baseStem}%`).all();

  if (results.length > 0) return { unique: false, reason: "semantic_collision", collision: results[0].slug };

  return { unique: true, slug: normalizedSlug };
}
```

## 3. Thin-Content Prevention Logic (The Activation Gate)
An entity generated by the worker must not be indexed until it possesses "Information Gain" (real user data).

```typescript
// Cloudflare Worker Cron (Runs hourly)
export async function activateEntitiesTask(env: Env) {
  // Find inactive entities
  const pending = await env.DB.prepare("SELECT id FROM p_entities WHERE is_active = 0").all();
  
  for (const entity of pending.results) {
    // Count live generation assets linked to this entity's styles
    const proofCount = await env.DB.prepare(`
      SELECT COUNT(*) as cnt FROM posts p
      JOIN p_entity_styles es ON p.style_id = es.style_id
      WHERE es.entity_id = ? AND p.is_public = 1
    `).bind(entity.id).first('cnt');

    // ACTIVATION THRESHOLD: Minimum 12 unique posts
    if (proofCount >= 12) {
      await env.DB.prepare("UPDATE p_entities SET is_active = 1, updated_at = CURRENT_TIMESTAMP WHERE id = ?").bind(entity.id).run();
      // Trigger Next.js On-Demand Revalidation via API
      await fetch(`https://picfomo.com/api/revalidate?secret=${env.REVAL_SECRET}&tag=programmatic`);
    }
  }
}
```

INSERT INTO p_entity_edges (source_id, target_id, edge_type, weight)
SELECT ?, e.id, 'related_intent', 1
