# Visual Indexing Engine

## 1. Image SEO Infrastructure
In the AI portrait niche, the image *is* the product. Google Image Search and Google Lens are primary discovery vectors.

### A. Procedural Semantic Renaming
Never serve `uuid.webp`. We must build an edge worker or S3 upload hook that renames the file based on its semantic properties.
* **Logic:** `[brand]-[aesthetic]-[use-case]-[gender]-[id].webp`
* **Example:** `picfomo-corporate-studio-lawyer-female-9x2b.webp`
* *Algorithmic Rationale:* Google extracts heavy contextual meaning from the filename. This guarantees exact-match keyword association before the image is even processed by computer vision.

### B. EXIF Metadata Injection Pipeline
During the image generation and compression phase (`browser-image-compression` / server-side sharp), inject EXIF data.
* `Software`: "PicFomo AI Engine"
* `Copyright`: "PicFomo"
* `Description`: The user's prompt or the style description.
* *Algorithmic Rationale:* Google explicitly reads IPTC/EXIF data for rights management and contextual understanding. It establishes authoritative origin.

## 2. Dynamic OpenGraph (OG) Generation
Social CTR (Click-Through Rate) is driven by the "Delta Fascination."
* **Implementation:** Use `@vercel/og` or Cloudflare's equivalent. 
* **The Template:** When `/post/[id]` is shared, the OG endpoint dynamically composes an image:
  * A stark, bold split-screen. 
  * Text overlay: "Generated in 20 Seconds on PicFomo."
* *Psychological Impact:* Increases social CTR by 300%. High social traffic signals to search engines that the URL is a popular, authoritative node.

## 3. Semantic Alt-Text Automation
Alt-text must be descriptive for accessibility (ADA compliance) and SEO.
* **Implementation:** The DB must construct the alt-text string dynamically.
  ```typescript
  const altText = `High-resolution ${style.name} AI portrait generated by PicFomo for ${useCase.title} in 20 seconds.`;
  ```

## 4. Image Sitemap Systems
Standard XML sitemaps do not guarantee image indexing.
* **Implementation:** Generate a dedicated `image-sitemap.xml` that explicitly lists the `<image:image>` tag, the `<image:loc>`, and the `<image:title>`.
* **Licensing Integration:** Combine this with the `ImageObject` schema (which includes `acquireLicensePage`). This forces Google Images to display a "Licensable" badge, making the image look like a premium, proprietary asset rather than scraped content.
